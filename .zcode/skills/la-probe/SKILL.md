# LA 探针实验 SOP（三机台架版）

> 铁律先立：**判据先行、探针惰性必须实测证明、解码规则窗前预注册、绝不在 ISR 里 printf**。
> 正本时间线=daily 2026-10-02；实验正本=计划 §26；分析器=tools/la_analyze_v2.py（burst 模式）。

## 一、编码设计（写代码前过这张表）

1. 单脚脉冲计数编码：固定 mark 宽（≥4-8 采样周期）+ 丛内固定间隔 + **丛间 idle guard ≥2-3× 丛内间隔**（NEC 惯例；无 guard 的背靠背事件必并丛——A2→A2b 修的就是这个）。
2. 脉宽下限：10MHz 采样下 mark ≥0.5µs（=5 样本）；<2 样本的脉冲可能整段漏检。改采样率先重算这张表。
3. 设备本地编码表各异时（我们的现状），SOP 文档必须带三机对照表——解码器不猜。
4. 打点位置语义必须逐事件声明：**决策时刻 vs 硬件动作时刻 vs 空中时刻**（TXDS=真空尾；SetChannel=决策；kick≠空中起点，PLL 锁定差百 µs 级）。
5. 时戳打点顺序：脉冲若在 RTC/SysTick 打点之前，会造成恒定偏置（可吸收）；在之后则零污染——两种都要在 SOP 里写明。

## 二、开销预算（<1% 行业线）

6. 每脉冲成本历史实测 1.125µs（P 系列，遥控 80M）；判例：圈占比 1.9%=可接受、13.5%=不可。
7. 事件率×（丛+guard）总账必须算出来写进 SOP；超 1% CPU 砍事件或砍 guard。
8. ISR 内只允许 GPIO 寄存器直写 + volatile；BK3633 无 DWT，开销标定用"N 次紧循环打点+LA 测总时长"法。

## 三、采集（用户一次点击的参数）

9. **单台 LA 多通道**：跨节点相对时序必须同机采（skew≤1 样本）；三台独立 LA 的时戳禁直接比。
10. 参数基准：10MHz / 10s / 100M 深度满（10ms 格系统绰绰有余）；要 5MHz×20s 长窗先把脉宽加宽到 ≥2µs。
11. 采前链路标定：已知方波喂 LA（本仓先例=T0：20.83kHz 三法互洽）或每机 boot 5 脉冲自检落在采集窗口内（可选：采前 RTS/dap-rst 三机齐复位，自检脉冲=通道链路证明）。
12. 共地、地线短、焊排针不用夹子；打点变量/GPIO 访问 volatile。

## 四、解码（规则窗前预注册）

13. 丛分段阈值居两档设计中点、留 ±25% 容差；**相邻事件邻对表**预注册（如踏频 7=4+3、桥 10=4+6 合并丛）。
14. 并丛率>10% 或意外丛>5% = 解码不可信，先修 guard/阈值再下结论（J4 判据）。
15. 周期切分用固定相位锚点（桥 4 脉冲=200ms 块界），不用浮动窗；首末丛只作边界不作统计。
16. 统计输出：N/mean/min/max/σ + p5/p50/p95 + 直方图；报告带不确定度声明（单沿 ±1 样本、区间 ±2 样本、时基 ±50ppm）。

## 五、判据与回退

17. 探针惰性判据：有/无探针窗关键指标差 <3pp（J3）；超限=探针扰动，结论作废。
18. 观察者效应对照：正式结论前跑一轮少打点/无打点版本对比。
19. 采集失败≠白采：失败模式本身入知识卡；原始 CSV/bin+解码脚本+参数版本全部归档（可复现）。
20. 回退：探针轮结束整包烧回业务包（遥控 R1bis_S6pre/桥 B2_S32+0xCC/踏频 A2 即业务态）；PROBE_LA_TX 必回 0 恢复串口 RX。

## 坑清单（本仓实测）

- **串口 TX 线与探针线并行走线=容性串扰 0.1µs 尖刺**（A2 实测：桥 21750 个假沿，打印密集时链成假丛）——解码必带脉宽过滤 ≥0.3µs；布线避免串口/探针并行，优先分开或绞线

- p1/p0/rx=[HB] 字段是每秒率不是累计；p0≈0 先查记录器自己 RTS 压没压遥控（A2b 乌龙）
- 桥 fresh-boot 后数分钟 spi staged 积压爬坡=非故障（staged 清零+idle 回落即愈）
- GBK 源文件禁 python 读写往返（用 Edit 工具）；#if 0 注释必须单行闭合否则吞代码块
- KingstVIS .bin 无采样率元数据，--srate 必须显式给；CSV 才有绝对时间列
