# 2026-11-26 调研：视觉对准（像素偏差 → yaw + 固定深度抓取）

**一句话建议：够用——车停在标定好的停位点，只转 yaw（GM6020 转台电机）+ 用 2s 内视觉帧伸臂即可夹住；必须把 vis_depth（固定深度，mm）从默认 300 标到约 230~250，停车位用遥控触发、别押在视觉上。代码依据 taurus_h7_all @0809ebd。**

## 1. "停车 → 只转 yaw + 伸臂"够不够
- 像素→角度：Δx（横向像素偏差，px）本质是角度量：所需 yaw ≈ Δx × FOV_h/320（FOV_h=相机水平视场角，°，**上车量**）。GM6020 每度 22.75 ECD（编码器计数，8192/360°），故 yawk_x100 ≈ FOV_h/320×2275；FOV 60° 时 ≈427，在 `ik yawk` 范围 ±1000（≤0.44°/px）内。
- 横向覆盖：yaw 后目标距离不变，d=√(X²+Z²)（X=横向偏差，mm；Z=真实深度，mm），须 ≤290mm（ik_solve 按 L1+L2−10 钳位，arm_task.c L412）。X_max=√(290²−Z²)：Z=250→147mm；Z=280→69mm；**默认 depth=300=L1+L2 → 横向余量为 0，必改**。
- 误差源（按影响排序）：① depth 假设误差——停车点距离偏差 ±30mm 直接沿视线平移夹爪落点；② k（毫米/像素）距离依赖——比例 ∝ Z/Z_cal，停车散布 ±30mm 时高度误差 ≈ y_px×k×12%（y_px=80px 约 8mm）；③ 相机不在 yaw 轴上的视差——偏距 50mm 转 30° 时 ≈26mm（**上车量**）；④ 帧延迟/flag 抖动——代码已兜底：超 2s（TEACH_VIS_FRESH_MS=2000）退回示教路点。
- 容差：果径 30mm vs 夹爪口 80mm → 位置容差 ±25mm，上面误差链可压进容差。
- 必须动底盘的判据：a) |Δx|≥160px（帧边钳位 prot_vision.c L464，角度换算不可信）；b) `ik vis` 打印 "(CLAMPED to reach)"（√(X²+Z²)>290mm，够不着）；c) 所需 yaw 超出转台机械行程（**上车量**）。操作判据：停位点保证 Z∈[220,260]mm 且 |Δx|≤100px，否则挪车。

## 2. vis_depth 最快标定（现有命令，免手算）
前提：`ik learn sh0/sh90/el0/el90` 已做（ik_valid=1）。learn 到的 EXTEND 路点把夹爪长度等工具偏置自动吸收进 depth，无需单独建模。
1. 车停树前预定停车点，视觉 flag=1，`ik status` 记下 last_vis=(x,y)。
2. `teach enter` 释力，手拖臂让夹爪对准果子 → `pick learn 1`，记下打印的 sh/el 脉宽。
3. 退出 teach，发 `pick vis <x> <y>`（用第 1 步的像素值）→ 对比输出的 sh/el 与第 2 步学习值。
4. 迭代 2~4 次：`ik depth` 主要改 sh；y_px≠0 时 `ik k` 改 el；`ik dy` 先用卷尺量相机光轴到肩轴平面的高度差填入（默认 0，即高度只由 −y_px×k 决定）。直到 `pick vis` 输出 ≈ 学习值。
5. `ik save` 落盘标定；`pick apply` 后 `pick save` 落盘路点。
- 交叉验证：标完的 depth 应 ≈ 卷尺量的肩轴到果子水平距离；k 应 ≈ Z_cal×FOV_h/(320×57.3)。

## 4. 停车触发
建议：**定停位点 + 遥控触发**。地面标记或固定线计数停车，司机三击（KEY_EVT_TRIPLE → pick_run，arm_task.c L1478）触发抓取。理由：
- 代码已有兜底：pick_run 只用 2s 内新鲜帧，否则退回示教路点——视觉不稳不会乱动；
- "flag 有效 + 偏差小于阈值"自动停把停车决策押在视觉上：漏检/光照变化 → 反复起停或停不住；且阈值有物理意义的前提是 k 已标定，先后顺序倒挂；
- 可选门控（约半天）：车停稳后要求 flag 连续 N 帧有效才允许 pick run，只做允许/禁止，不参与停车决策。

## 上车要量的清单
1. FOV_h，或直接在 250mm 距离量每像素毫米数 → 定 `ik k`
2. 停车点散布：同点位停 5 次量深度/横向差 → 定 depth 取 230 还是 250
3. 相机光轴相对 yaw 轴的偏距与高度差 → 视差修正与 `ik dy`
4. GM6020 转台机械行程 → yaw 可用范围（判据 c 的阈值）
5. vis_depth 标定值（§2 流程）与 yawk 实测（转台转正一次，ΔECD/Δpx）
6. `ik learn` 四点 sh0/sh90/el0/el90——一切 IK 的前提
