### 任务1：新 H723 板 bring-up（当前）

- **harness（通过标准）**：
  1. Keil/命令行编译 ALL 基座 0 Error；hex 生成时间新于源码改动。
  2. 新调试器（DAPLink U 盘拖拽 或 Keil CMSIS-DAP）烧录成功，复位后芯片运行。
  3. BMI088：非全零且温度随加热趋近 40°C（DES_TEMP=40，TIM3 CH4 PWM 加热），yaw/pitch/roll 静止小幅漂移、转 90° 跟 90°。

  5. CAN1↔CAN2：两路接线后，CAN1 发 ID 0x123 / data 0x01..08，CAN2 收到相同帧（或反向），rx 计数增长。

### 任务2：寻线模块串口数据流

### 任务3：串口总线舵机 + 可调电源电流

- **harness**：

  2. 发角度指令 → 读回实际角度一致；机械臂关节运动可复现。
  3. 电流：静态 / 运行 / 堵转三档 mA 数据，判断电源与驱动余量。
