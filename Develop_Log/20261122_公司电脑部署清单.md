## 五、明天现场工具速查

### 舵机验明正身（CH343 TXD→舵机 Signal，共地）
```
python Tool/serial_probe/servo_probe.py           # 自动扫口扫波特率
python Tool/serial_probe/servo_probe.py -p COM7 -i  # 交互模式，手敲 #000PRAD! 等
```
- 有 `#000PZServo...G!` 应答 = 串口总线舵机 → agent 激活 prot_xb_servo（MC02 上挂 UART7 PE7/PE8）
- 无应答 = PWM 舵机 → 用 MC02 板载 8×3P 排针（对照官方 CtrBoard-H7_TIM 例程选通道）

### 巡线模块串口（CH343 TXD↔RXD 交叉接模块，共地；先按手册校准！）
```
python Tool/serial_probe/line_uart_probe.py                 # 自动扫口，数字+模拟都开
python Tool/serial_probe/line_uart_probe.py --analog-only   # 只看模拟量（置信度用）
```
- 期望持续滚出 `$D,...#` 和 `$A,...#` 帧（模块上电默认不发，脚本已自动发 `$0,1,1#`）

### MC02 板首次上电
- USB 线接板 → Keil 里 Download（F8）烧 ALL 基座 → 复位
- 期望：板载 IMU 恒温加热到 40°C、VOFA/串口出 yaw 曲线（静止漂移小、转 90° 跟 90°）

## 六、常见坑（都是踩过的）

| 坑 | 对策 |
|----|------|
| Keil 增量编译不认外部改的文件 | 编译日志里没有 `compiling xxx.c...` 就用 `-r` 全量重编 |
| Python 脚本中文乱码 | 命令行前加 `set PYTHONIOENCODING=utf-8` |
| CH343 插上没 COM 口 | 换 USB 口/装驱动；用 `serial_probe.py` 的自动扫口能列出现有口 |
| 模块红灯快闪 | 巡线模块未校准，按手册 KEY1 长按 → 黑线 3s → 按键 → 白线 3s → 按键 |
| gitee clone 慢 | 换 github 镜像或 --depth 1 |
