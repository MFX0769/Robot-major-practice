## 门控规则（记这 5 条就够）
1. 上电 = 保护模式，底盘/机械臂/yaw 全零；没有遥控器时右拨杆读数是 0。
2. `mode manual` 才能发机械臂命令；它锁住底盘。`mode protect` 或 `stop` 回到全零。
3. `chassis line` **连发两条**（5 秒内）才启动巡线；巡线运行时机械臂命令被拒绝。
4. `chassis motor <i> <电流>` 不受上面任何限制：保护模式下也会转，1.5 秒自动归零，限幅 ±3000。
5. yaw 必须先 `yaw probe`（或 `yaw dir 1` / `-1` 手动给方向）才接受目标；命令 10 秒后自动归零。
6. 任何设备不动，先 `diag` 看 `last_reject`；日志/控制台/USB/DBUS 的丢弃和帧间隔都在同一快照里。

灯：绿=空闲 蓝=就绪(已释力) 红=录制 黄=已保存 青=回放 紫闪=中止；状态变化蜂鸣 60 ms。
每秒一行 `[CAN] c1 tx= rx= tec= rec= bo= off= fix= | c2 …`：**看 rx 和 off，不要看 tx**（不重传模式，没人应答 tx 也涨）。
巡线整定：默认已经是 `chassis pid line -12 0 0`（调研发现旧 -50 的转向量相对 ±100 量程过大）；先跑直线，摆头就往小调，拖尾就略回加。丢线转向自动跟随 kp 符号。

## 分步上电（每步都有退路；一步不过先别往下走）
**第 0 段：不接 24V，只接调试口**
1. 烧录：`py Tool\flash_console.py go`（编译+烧录+读 6 秒）。应看到 `=== Taurus @ DM-MC02 …` 和 `[ARM] init: … flash ok=1`。
2. `[CAN]` 行：两路都是 `rx=0`、`off` 持续增长 = 正常（总线上没人应答，约每秒进出十几次，估算）。接上 24V 后 `rx` 应开始涨、`off` 停止增长。
3. `flash test` → `flash test PASS`。`uart` → 敲命令时 `console(U10) rx=` 跟着涨。

**第 1 段：24V 上电，轮子离地。注意：总线舵机上电会自己转到 1500，手先拿开**
4. `servo ping 2`、`servo ping 1`、`servo read 2` → `rc=0` 说明舵机总线通，且位置读得回来（舵机的 5V 由 24V 经板载电源给出）。
5. `chassis status` → 四个电机 `on=1`，id 分别是 0x204/0x202/0x203/0x201。全 `on=0` → 查 CAN1 电源/线/终端电阻。
6. 逐个轮子：`chassis motor 0 800`（下标 0~3 = 左前/左后/右前/右后），记下每个轮子的转向。不动 → 该电调的 ID 或接线。
7. 肩肘：`mode manual` → `joint status` → `joint shoulder +30`、`joint elbow -30`。
   默认限位只有 1400~1600（500~2500 对应 0~270°，所以约 ±13°），要大幅度动先 `joint limit shoulder 500 2500` 和 `joint limit elbow 500 2500`。
8. yaw：`yaw status` 看 `on=1` → `yaw probe`（开环给 +4000 持续 150 毫秒，约 16% 电压）→ 打印 `dir=+1` 或 `-1` → `yaw step 100`。
   提示 `within 150 ECD of a limit` → 臂离行程两头太近，先推到中间再探测。
   提示 `no motion` → 调 `yaw limit` 没用（探测电压封顶 4000）：查 24V 和 ID4 灯；或手动 `yaw dir 1`，一动就停且 `fault=1` 的话 `yaw fault clear` 后 `yaw dir -1`。
9. 死程序（出厂已内置 6 月表演；不读舵机也能跑）：
   ```
   pick run           # 跑表演；再发一次 = 停；板载 PA15 三击、巡线中拨左摇杆同样
   pick save          # 只把标定/默认存进 Flash（可选）
   ```
   要录自己的动作（优先，验收更像"摘果"）：`mode manual` → `joint limit shoulder 500 2500`、`joint limit elbow 500 2500` → 长按 PA15 进示教 → 拖到位置 → `pick learn 0..4` → `pick run` 试 → `pick save`。
   读不到舵机就用 `wp 0..4 <sh> <el>` 按数字设路点。
   夹爪开合：`pick open 1100` / `pick close 1450`（当前默认=6 月实测值）；每步时间：`pick time 1 800`（毫秒）。
10. 拖动示教（第 4 步 `servo read` 能读回位置才可用）：长按 PA15 2 秒→蓝（释力）→ 短按=原点 → 短按=开始录（红）→ 拖 → 双击=保存（黄）→ 双击=回放（青）→ 长按 2 秒=退出。
11. 巡线：车放线上，`chassis line` 连发两条。`chassis stop` 或 `stop` 停。
    上电 2 秒后启动的巡线**没有缓冲，立刻看线**；一上来就丢线会按记忆方向转 0.7 秒然后停。
12. 视觉（可选）：`vis` 看 `bytes/frames` → 默认深度已是 250 mm（`ik depth` 可改）、`ik k 1.5`（毫米/像素）→ `pick auto on` → `pick run` 用 2 秒内的视觉帧重算"伸出"姿态。
    要标真正的 Z：四点 `ik learn sh0/sh90/el0/el90` → 在树前长按 PA15 拖到夹得住的位置 → `pick learn 1` → `ik learn here`（自动把前向距离写入深度，有视觉帧时连高度偏置一起算）→ `ik save` / `pick save`。
    没有视觉电脑：`pick vis 100 -50` 手动模拟一帧（右 100、上 50 像素）。`ik yawk` 默认 0，yaw 不跟视觉。
13. 避障（1 路前向 TF-mini）：模块 TX → 排针 11（UART9_RX/PD14），5V/GND 就近接；先 `avoid status` 看 `online=1`、`frames` 在涨、`valid=1`。
    出厂默认单位 cm（TF-mini 默认输出），被改成 mm 的模块先 `avoid unit mm`。`avoid run` 可无传感器强行走一遍流程。
    距离/方向现场调：`avoid shift 300`（横移毫米）、`avoid fwd 450`（前进毫米）、`avoid side left|right`、`avoid app 300`（触发距离毫米）。
    里程计第一次标定：`avoid odo` → 遥控直行一段、量实际毫米数 → `avoid calib <毫米数>`；里程计、横移/前进距离和左右方向 `pick save` 后掉电保留；`app`（触发距离）和 `unit`（cm/mm）每次上电要重设。
    安全：任一段 8 秒走不完就 ABORT 停车；`chassis stop` 或 `avoid off` 立即取消。

## 应急表
| 现象 | 看哪里 | 做什么 |
|---|---|---|
| 遥控器方向不对 | `rc` | 映射已按 DBUS 改（右摇杆平移、左摇杆横旋转）；哪个方向反了用 `chassis map vx|vy|wz -1` 翻，`pick save` 保留 |
| 拨到"巡线"档车不走 | `[SYS]` 行的 `mode=` | 巡线要两个拨杆配合：底盘拨杆在下，同时全局模式不是保护（mode≠0） |
| 某路 CAN 没数据 | `[CAN]` 行 / `can stat` 的 `rx` | `rx` 恒 0 = 没人应答：电调电源、CANH/CANL、终端电阻、接错 CAN1/CAN2 |
| 总线反复进退出错状态 | `off`、`bo` | `bo` 长时间为 1 → `can recover 1` 或 `can recover 2`；其余靠自动恢复 |
| 单个轮子不转 | `chassis status` 的 `on` | `on=0` 查该电调 ID（大疆电调惯例：绿灯闪的次数 = ID，C610 手册未核对）；换位对比 |
| 6020 灯：橙 2 次/秒 | 总线 | ID 重复 |
| 6020 灯：红常亮 | CAN2 | 收不到电压帧：`can stat` 看 c2 的 `tx` |
| yaw 一动就停、`fault=1` | `yaw status` | 线接反：`yaw fault clear` 后 `yaw dir -1` |
| `probe: no motion` / `probe stopped` | 提示文字 | 停在限位 150 ECD 内→把臂推到中间；真没动→查 24V、ID4 灯，或 `yaw dir 1` / `-1` 手动给方向 |
| yaw 回放中途停、`fault=2` | `yaw status` | 6020 反馈丢了：查 CAN2/24V，`yaw fault clear` |
| 舵机不回话 | `uart` 的 `servo(U1) rx/err`、`servo ping` | `rx=0` 查 5V（PC15）和 PA9 单线；`err` 猛涨查波特率/地线 |
| 舵机能动、`servo read`/`pick learn` 报错 | `learn failed: servo read` | 用 `wp` 按数字设路点，死程序照跑 |
| 控制台没反应 | 换另一路输入 | DAP 虚拟串口 ↔ 板载 USB：`py Tool\flash_console.py --port COMx send "…"` |
| 串口各路有没有数 | `uart` | 一行列出 控制台/巡线/视觉/遥控/舵机 的接收字节数 |
| `save FAILED` / `flash test FAIL` | `teach status` 的 `flash=` | RAM 里的轨迹还在，重启才丢；重新 `pick save`，不行就重录 |
| 存轨迹时提示 save rejected | — | 巡线在跑：先 `chassis stop`（写 Flash 时 CPU 停 1~2 秒） |
| 车子自己动 / 臂乱动 | — | `stop`（全零）。示教里长按 PA15 2 秒退出 |
| 示教卡住 / 舵机配置模式退不出 | `mode status` | `servo run`；`stop` |
| 遥控器没反应 | `uart` 的 `dbus(U5)` | 不影响其余功能；`rx=0` 查 PD2 和接收器供电 |
| 激光 `online=0` / `valid=0` | `avoid status` | 查排针 11=PD14、5V/GND、115200；`frames` 涨但 `valid=0` = 强度不足/距离 FFFF；出厂单位 cm，改过输出用 `avoid unit mm` |
| 避障横移不够/方向不对 | `avoid status` 的 `this leg dx/dy` | 先 `avoid calib` 标里程计；方向用 `avoid side` 或 `chassis map vy -1`；任一段超时 8 秒会停车 |
| 避障回不到线 | `avoid status` = `RELINE`/`ABORT` | `RELINE` 会再慢速回找 150 mm；`ABORT` 已停车，挪车/救场后 `avoid run` 重试 |
