# 机器人实践小车——课设背景信息

来源：知识库 `tech/2025Q4_机器人实践小车——嵌入式.md`

---

## 硬件方案

**主控平台：** STM32H7（战队自研板）
- 理由：刚写了该平台 BSP 库，熟悉度高；预留计算能力给机械臂等机构
- 挑战：BSP 库未经过实战检验

## 软件方案

- **开发链：** STM32CubeMX 生成代码 → VS Code 编辑 + Git 管理 → Keil 编译烧录调试
- **操作系统：** FreeRTOS

## 任务架构

### 1. 状态机任务
- 系统解锁 / 手动自动切换 / 失控保护

### 2. 底盘任务
- 麦轮解算：底盘目标速度 → 轮速
- 轮速 PID 控制
- CAN 通讯发送电机控制指令

### 3. 巡线任务
- 8 路灰度传感器数据读取（USART）
- 光电开关避障
- 巡线 PID → 计算底盘目标 Vz（yaw 速度）

### 4. 视觉通信任务
- 向视觉模块发布数据（USART）
- 解包视觉数据：果树检测、停车、果子位置、夹取时机等

### 5. 上层机构任务（夹取机械臂）
- 夹取机构状态机（参考战队机械臂代码）
- 龙门架运动学解算
- 电机位置 PID 控制 → CAN 通讯
