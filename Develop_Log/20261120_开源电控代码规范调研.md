## 二、各校电控开源与规范文档（任务 B）

### 有成文规范的（skill 素材核心）

**1. 上交《电控部代码规范》** — [SJTU-RoboMaster-Team/Electronic-control-code-specification](https://github.com/SJTU-RoboMaster-Team/Electronic-control-code-specification)（2020 起，全文 223 行已读取）：
- 文件头固定注释块：`@FileName/@Description/@author/@note` + 版权行
- 头文件 6 段式结构：`/*** MAP ***/ /*** CONSTANT VALUE ***/ /*** TYPE DEFINE ***/ /*** SPECIFIC INIT CONFIGURATION ***/ /*** EXTERNAL VARIABLES ***/ /*** APIs ***/`——MAP 段管脚映射二次定义（句柄/定时器通道/GPIO 不写死）
- 变量：驼峰命名（targetAngle），写全单词；公认缩写表（arg/buff/clk/cmd/cmp/cfg/dev/err/inc/init/max/msg/min/para/prev/reg/sem/stat/sync/tmp）
- 常量优先 `constexpr` 替代宏；宏全大写+下划线；引华为规范"尽量用函数代替宏"（宏无类型检查/副作用/难打断点）
- 函数：大驼峰（MainControlLoop），类内 Get/Set 前缀
- 注释：Doxygen `@brief/@param/@return/@arg`，重要函数加 `@author`
- 结构体大驼峰+`_t` 后缀、枚举大驼峰+`_e` 后缀
- 类规范：**严禁 new（堆栈小）**；Init/Reset 完成初始化；**Handle 模式**（`chassis.Handle()`）；"尽量读取而非写入"（targetAngle 在 Chassis 内赋值而非 Remote）

**2. 湖大《架构介绍与开发指南》+《必须做&禁止做》** — [basic_framework/.Doc](https://github.com/HNUYueLuRM/basic_framework/tree/master/.Doc)：
- **BSP/Module/APP 三层**：BSP 建 HAL 之上封装外设；Module 基于 BSP 打造**硬件无关接口**——"应用层不应出现任何与片上外设相关的代码"；不同兵种只重写 APP 层
- CubeMX usercode 块纪律（否则重新生成被覆盖）；UTF-8 编码；物理量统一标准单位制
- 函数=动宾短语≤4 词首字母大写（`SetMotorControl`）；变量=下划线小写（`gimbal_recv_cmd`）；类型=首字母大写+下划线+后缀（`IMU_Data_t`、`can_instance_config_s`）
- 接口注释统一写在 .h；static 私有函数在 .c 注释；每模块配套文档（总体说明/代码结构/外部接口/使用范例）
- **安全检查 "treat your users as idiots!"**
- 铁律：**禁止临界区内延时**（关中断导致时基卡死，用 bsp_dwt 计数差值延时）；共享数据加锁（位互斥锁而非 osMutex，保证中断可用）；**NO WARNING（-Werror）**；bsp/module 必须带文档+使用示例+调试条件编译

## 三、八维度规范清单（任务 C —— skill 素材）

### 1. 文件/目录分层
- **三层铁律**（湖大）：BSP（HAL 封装）→ Module（硬件无关模块）→ APP（兵种业务）。"应用层不应出现任何片上外设相关代码"。
- 本地对应现状：`Bsp/ → Protocol/ + Comm/ → Application/`，与三层同构，但 `Application/` 里混有 gimbal/shoot/ui 等旧比赛尸骸，应按兵种功能归拢。
- APP 层按功能分目录（Meta-NG：chassis/gimbal/shoot/infantry + `robot_def.h` 集中类型定义）。
- 每个功能一对 `.c/.h`（上交）；常用模块组配总头文件 `XXX_All.h`（上交）。
- 配置分级：总配置 `config.h` 最高，模块配置 `XXX_Config.h` 低于模块头文件（上交）。

### 2. 命名约定
- 变量：写全单词、体现功能（`targetAngle`/`gimbal_recv_cmd`）；公认缩写可用（arg/buff/clk/cmd/cmp/cfg/dev/err/inc/init/max/msg/min/para/prev/reg/sem/stat/sync/tmp——上交）。
- 函数：动宾短语≤4 词（`SetMotorControl`/`ChassisHandle`）。
- 类型：`XXX_t` 结构体、`XXX_e` 枚举（上交）；湖大变体 `IMU_Data_t`/`can_config_s`。
- 宏/常量：全大写下划线；**能用 const/constexpr 就不用宏**（华为规范，宏无类型检查、有副作用、难断点）。
- 私有（static）加 `_` 前缀或下划线后缀，指针可加 `p`/`ptr_` 前缀（湖大）。

### 3. 头文件与全局变量管理
- 头文件 6 段式（上交）：MAP → CONSTANT → TYPE DEFINE → INIT CONFIG → EXTERNAL VARIABLES → APIs。
- 管脚/句柄映射二次定义，不写死（上交 MAP 段）。
- 全局变量集中登记在头文件 EXTERNAL VARIABLES 段；**"尽量读取而非写入"**——目标值由拥有者模块赋值，别让遥控器直写底盘目标（上交 Handle 思想）。
- 共享数据加锁（湖大）：位互斥锁优于 osMutex（中断可用）。

### 4. 任务函数写法
- FreeRTOS：`osThreadDef` + `osDelayUntil` 定周期；**禁止临界区内延时**（湖大铁律——关中断卡死时基；需要短延时用 DWT 计数差值）。
- 任务结构：`init() 一次 + for(;;){ 周期工作; osDelayUntil; }`；模式切换用状态机枚举。
- 类/模块 C 写法：构造只做零值，`Init/Reset` 完成全部初始化；`Handle()` 完成一次整周期计算（上交）。
- 严禁 new/malloc 滥用（堆栈小，上交）。

### 5. 调试/日志
- 调试打印必须挂总开关宏（本地已有 `DEBUG_TEXT_ENABLE`/`DEBUG_VOFA_ENABLE` 互斥模式，保持）；条件编译+log 输出是 bsp/module 的必备项（湖大）。
- 波形用 VOFA+ 通道集中管理（robowalker 达妙板篇有 USB_CDC+VOFA+ 专章）。
- **NO WARNING**：-Werror 心态，不带着 warning 提交（湖大）。

### 6. 注释与文档
- 文件头固定块：`@FileName/@Description/@author/@note`（上交）。
- 接口注释写在 .h（Doxygen `@brief/@param/@return/@arg`）；static 函数在 .c 注释；关键步骤 `//` 解释到"中等水平队员能懂"（上交）。
- 每个新模块配文档：总体说明/代码结构/外部接口/使用范例（湖大）。
- 修改日志走 Develop_Log（本地惯例）+ CHANGELOG（CAT_BSP 有）。

### 7. 提交纪律
- commit 粒度=一个逻辑变更；`git status`/`git diff --stat` 先看后动（本地 CLAUDE.md 已有，保持）。
- .gitignore 排除编译产物（MDK-ARM/rm_main/、*.axf/hex/map/uvguix）；Meta-NG 的 .gitignore 可参考。
- 分支：功能分支→dev→主分支（湖大）；user.name 用英文缩写。
- CubeMX 生成文件只动 USER CODE 块（湖大）。

### 8. 安全检查
- "treat your users as idiots!"：对外接口做空指针/范围检查（湖大）。
- 上电默认安全态：PROTECT 模式零输出（本地 arm/chassis 已有 force_zero 模式，保持）。
- 数值限幅：PID maxout + 输出钳位双保险。
