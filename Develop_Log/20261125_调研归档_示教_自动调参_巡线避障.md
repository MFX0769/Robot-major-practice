## 一、拖动示教调研结论

### 1) 推荐最小状态机

`IDLE → TEACH_ARMED → ORIGIN_SET → REC → SAVED → PLAYBACK → IDLE`，异常任一态进入 `ABORT → IDLE`。

| 环节 | 进入条件 / 动作 | 为什么需要 |
|---|---|---|
| IDLE 安全态 | 电机未使能或正常控制模式；只认按键 | 防止上电抖动/误触直接让臂失控 |
| 进入示教 | 长按 2s，抬键瞬间判定；检查电机已使能、零点有效、CAN/UART 通信正常 | 大臂示教都要求先处于零力/拖拽模式且使能明确 |
| 原点/起点标定 | 短按，把当前 yaw ECD + 肩/肘脉冲 + 夹爪 PWM 记为 P0 | 回放要有统一坐标基准 |
| 开始记录 | 短按，清缓冲、`count=0` | 明确区分设原点和录轨迹 |
| 拖拽采样 | 20Hz tick + 位移阈值门控；GM6020 拖动时关闭位置环、只读 ECD | 无扭矩传感器，不能做真实导纳控制；采样必须来自反馈而非指令 |
| 手动插点 | REC 中短按，强制记一帧 | 关键姿态不能被阈值漏掉 |
| 结束保存 | 双击，校验 `count>=2`，写 Flash，CRC 校验 | 避免保存空轨迹 |
| 异常中止 | REC 中长按 2s，或通信超时 / 关节超限位 / 速度超限 → 丢弃缓冲 | 单键必须有安全出口 |
| 回放切换 | SAVED 态双击 → 先回 P0（推荐），再固定周期输出 | 避免从任意姿态直接起跑 |
| 回放中停止 | 短按停止；长按 2s 紧急停止并回 IDLE | 单键必须随时可停 |

### 2) 单按钮映射（方案 A，推荐）

硬前提：必须有 LED 或蜂鸣器反馈状态；只有 1 个按键且无显示，任何映射都会误触。

判定规则：
- `150ms~500ms = 短按`
- `500ms 内第二次短按 = 双击`
- `2s~5s = 长按2`
- `≥5s = 长按5`
- 长按不在 2s 到点立刻动作，避免长按5误触长按2。
- 100ms 消抖意味着最短有效按压 ≥150ms；连按窗口 400~500ms。
- 任一态 30s 无操作自动回 IDLE。

映射：
- IDLE：长按2 → TEACH_ARMED；长按5 → 请求删除已存轨迹，再双击确认。
- TEACH_ARMED：短按 → 标定 P0。
- ORIGIN_SET / READY：短按 → 开始 REC；长按2 → 退出。
- REC：短按 → 手动插点；双击 → 结束并保存；长按2 → 放弃本次记录。
- SAVED：短按 → 重新标定 P0；双击 → 回放；长按2 → 退出。
- PLAYBACK：短按/双击 → 停止；长按2 → 紧急停止回 IDLE。

另两套对照：
- 方案 B「按住才拖」：REC 中按住键 = 关力矩允许拖动并采样，松开 = 冻结并自动记一帧，双击结束。误拖风险最低，但需要两手配合。
- 方案 C「连按菜单」：IDLE 中 2 连按示教、3 连按回放、4 连按删除确认。状态少，但误判率高，不推荐。

### 3) 采样与存储

| 方式 | 数据量（512 点上限） | 存储压力 | 回放平滑度 |
|---|---|---|---|
| 20Hz 定时 | 25.6s；每点 yaw ECD 2B + 肩 2B + 肘 2B + 夹爪 2B = 8B，共 4KiB | 最小 | 最好，等间距点线性插值 |
| 位移阈值触发 | 静止段不写，需带 dt | 中等 | 中等 |
| 手动逐点打点 | 10~50 点 | 极小 | 最差，必须插值+限速 |

建议：20Hz tick 做检测，阈值门控写入：`max(|Δyaw_ECD|, |Δ肩脉冲|, |Δ肘脉冲|) ≥ 等效 1°~2°` 或夹爪设定变化时写一点；短按强制写一点。缓冲满 512 时停止记录并报警，不静默覆盖 P0。

保存格式（通用）：
```text
Header:
  magic        u32   // 例如 0x54454143 "TEAC"
  version      u16
  seq          u32
  point_count  u16   // <=512
  period_ms    u16   // 50
  joint_mask   u8
  flags        u8
  reserved     u8[]
Points[512]:
  yaw_ecd      u16
  shoulder     u16
  elbow        u16
  gripper      u16
Tail:
  crc32        u32   // 覆盖 magic..最后一点
```
A/B 扇区交替：写到一半断电也不会两槽全废；擦写均摊；新槽 CRC 失败可回退旧槽。

### 5) 不要做

- 不做力/力矩传感器导纳/阻抗控制。
- 不做 ROS/MoveIt、视觉、碰撞检测、轨迹规划器。
- 不做暂停/继续、多轨迹库、用户编号管理。

- 不做夹爪力控；只记 PWM 设定值。

## 二、自动调参调研结论

### 1) 结论

- Ziegler–Nichols 临界比例度法：不适合 GM6020 直驱 yaw。它要求 Ki=0、Kd=0，持续增大 Kp（比例增益）直到等幅振荡，等价主动逼近不稳定边界；GM6020 有电子限位、重力/线缆偏载、死区和摩擦。
- relay feedback auto-tuning（继电反馈自整定，Åström–Hägglund）：有条件可做，但只能做受控版：小角度、位置反馈、限幅幅值、滞环、超时/限位/温度停止。
- 未找到 GM6020 / DJI 电机上公开的 relay 自整定完整代码或实测记录；只有通用 STM32/Arduino 实现。
- 关键纠错：0x1FF 是电压给定帧（2023 版手册范围 −25000~25000），0x1FE 才是电流帧（±16384 对应 ±3A），需固件 ≥1.0.11.2 且 Assistant ≥2.7 开启电流环。当前工程把 0x1FF 叫“电流”是量纲误称，做闭环前必须核对。

### 2) relay 参数起点（工程起点，非实测结论）

| 项 | 起点 | 说明 |
|---|---|---|
| d（继电输出幅值） | 450~900 LSB | 连续额定转矩 5%~10%；按官方 Kt=0.741 N·m/A、±3A=±16384 推算 |
| ε（滞环宽度） | 3~6 ECD counts | 位置噪声 1~2 counts 时取 2~3 倍噪声；13bit 下 1 count≈0.044° |
| W（软窗口） | ≤2°（≈45 counts） | 当前 yaw ECD 左右约 1260/6478，理论余量大，但限幅仍取 2° |
| 反馈 | 位置反馈 | 不要用原生 rpm：1 rpm 分辨率 + 空载速度波动 20~35 rpm，无法形成小范围极限环 |
| 判稳 | 连续 3 周期 Tu/a 偏差 ≤5%；正负半周不对称 ≤20% | 任一不满足则中止 |

流程：
1. 确认帧类型与固件。
2. 计算到左右电子限位的 count 余量，设 W。
3. 静止 200ms 测 n0（噪声峰峰值）。
4. ε=2~3·n0；d=450~900 LSB 起，2s 无振荡则 ×1.5，上限 4096。
5. 用位置反馈跑 relay，记录峰值时间戳与幅值。
6. 连续 3 周期满足判稳 → `Ku=4d/(πa)`、`Tu`；否则中止。
7. 恢复控制器，Kp 先取 `0.6·Ku` 的一半，Ki/Kd 暂不加。
8. 记录 d、ε、Ku、Tu、中止原因。

停止条件：|ECD−center|>W 或触限位；电流反馈>4096 LSB；温度>60℃；CAN 反馈间隔>10ms；10 周期未稳定或总时长>3s；正负半周不对称>20%；波形削顶或温度/电流持续上升。

## 三、巡线避障调研结论（临时版，需按新标准增量调研）

> 用户新标准：下面“最小方案”不能作为最终方案直接落地。必须由电赛/智能车比赛的完整开源工程支撑，并逐文件核对。对应调研子代理已被要求增量调研并追加记录。

### 1) 当前临时结论

最小方案骨架：8 路模拟量加权质心 → 横向偏差 e → 单环位置 PID 输出 wz（航向角速度）→ vx（纵向速度）固定、四轮差速；避障用 5 状态机 + 固定横向偏移。麦轮和普通四驱差异只在绕行横移：麦轮可直接横移，普通四驱用“转向—直行—回正”。

| 状态 | 进入条件 | 退出条件 | 行为 |
|---|---|---|---|
| NORMAL | 巡线有效且 d > d_app | d < d_app | vx=v_base，wz=位置 PID |
| APPROACH | d < d_app | d < d_stop 或 d 回升 >1.2 d_app 持续 200ms | vx 降到 0.5 v_base，冻结 PID 积分 |
| BYPASS | d < d_stop | 横向偏移达 s_bypass 且侧/前 d > d_clear，或超时 3s | 关横向修正，执行固定偏移 |
| RETURN | BYPASS 完成 | 巡线重新有效 30ms 或超时 1.5s | 反向横移回线，积分清零 |
| SEARCH | RETURN 超时 / 全白丢线 | 重新在线或 t_search 超限 | 按最后偏差方向单边搜索 |

首日 5 个参数：
- Kp 起点 2.5；Kd 起点 0.12；v_base 起点 0.6 m/s；d_app=vx×1.2s+0.5m；t_search=1.2s。
- Ki 默认 0；wz_max 2~3 rad/s；D 低通 20~40Hz。

加权质心公式：
- 标定每通道白值 `A_i^W` 与黑值 `A_i^B`；`l_i=clamp((A_i^W−A_i)/(A_i^W−A_i^B),0,1)`。
- `w_i=max(0,l_i−τ_line)^2`，τ_line=0.3；有效判据 `n_valid≥2 且 Σw≥0.15 且 |e|≤1.2`。
- `pos=Σ(i−3.5)w_i/Σw_i`，归一化 e∈[−1,1]。
- 全白进入 SEARCH；全黑按十字/终点处理，不进 PID。

轮速映射：
- 普通四驱：`v_L=vx−wz·T/2`，`v_R=vx+wz·T/2`。
- 麦克纳姆：`v_FL=[vx−vy−wz(l+b)]/r_w` 等，需要台架核对符号。
- 注意：报告写的是 C620；本项目是 M2006 + C610，0x200 电流限幅必须按 C610 核对。

对本项目的建议（只引用上面开源证据）：
- 位置解算抄 nvy-max 的加权质心结构；`intensity` 用“满量程标定值 − A_i”，低于阈值判丢线并按最后偏差符号饱和输出。
