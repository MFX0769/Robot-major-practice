# 底盘电机全链路分析

## 目标

在当前项目中打通底盘4个2006电机的完整链路。

## 参考代码

- 旧代码: `F:\机器人工程实践小车\RoboticMajor_Pratice_code`
- 舵轮代码: `F:\RM2026\code_buf\8009p\8009p\chassis_rudder_2025`

## CAN ID和总线分配

| 电机 | CAN ID | CAN总线 | 位置 |
|------|--------|---------|------|
| chassis_2006[0] | 0x204 | CAN1 | 左前 |
| chassis_2006[1] | 0x202 | CAN1 | 左后 |
| chassis_2006[2] | 0x203 | CAN2 | 右前 |
| chassis_2006[3] | 0x201 | CAN2 | 右后 |

## 电机打包规则

```
CAN ID 0x201~0x204 → 控制帧 0x200
  data[0:1] = motor[0].tx_current (左前/右后)
  data[2:3] = motor[1].tx_current (左后/右前)
  data[4:5] = 未使用
  data[6:7] = 未使用
```

## 全链路实现步骤

### 1. 电机声明 (prot_rm_motor.c)

```c
dji_motor_t chassis_2006[4];
```

### 2. CAN ID定义 (prot_rm_motor.h)

```c
#define CHA_LEFT_FRONT_2006   0x204
#define CHA_LEFT_BACK_2006    0x202
#define CHA_RIGHT_FRONT_2006  0x203
#define CHA_RIGHT_BACK_2006   0x201
```

### 3. 电机初始化 (can_comm.c → comm_can_init)

```c
dji_motor_init(&chassis_2006[0], DJI_2006_MOTOR, CAN_CHANNEL_1, CHA_LEFT_FRONT_2006, 36);
dji_motor_init(&chassis_2006[1], DJI_2006_MOTOR, CAN_CHANNEL_1, CHA_LEFT_BACK_2006, 36);
dji_motor_init(&chassis_2006[2], DJI_2006_MOTOR, CAN_CHANNEL_2, CHA_RIGHT_FRONT_2006, 36);
dji_motor_init(&chassis_2006[3], DJI_2006_MOTOR, CAN_CHANNEL_2, CHA_RIGHT_BACK_2006, 36);
```

### 4. CAN接收回调 (can_comm.c)

在 `User_CAN1_RxCpltCallback` 和 `User_CAN2_RxCpltCallback` 中添加：

```c
case CHA_LEFT_FRONT_2006:
case CHA_LEFT_BACK_2006:
{
    uint8_t idx = (id == CHA_LEFT_FRONT_2006) ? 0 : 1;
    dji_motor_get_single_data(&chassis_2006[idx], buf->rx_data);
    break;
}
```

### 5. 电机发送函数 (can_comm.c)

使用已有的 `Prot_CANx_Send_Frame` 函数：

```c
void chassis_can_send(void)
{
    uint8_t data[8];
    
    /* CAN1: 左前 + 左后 → 控制帧 0x200 */
    data[0] = chassis_2006[0].tx_current >> 8;
    data[1] = chassis_2006[0].tx_current & 0xFF;
    data[2] = chassis_2006[1].tx_current >> 8;
    data[3] = chassis_2006[1].tx_current & 0xFF;
    data[4] = data[5] = data[6] = data[7] = 0;
    Prot_CAN1_Send_Frame(0x200, data, 8);
    
    /* CAN2: 右前 + 右后 → 控制帧 0x200 */
    data[0] = chassis_2006[2].tx_current >> 8;
    data[1] = chassis_2006[2].tx_current & 0xFF;
    data[2] = chassis_2006[3].tx_current >> 8;
    data[3] = chassis_2006[3].tx_current & 0xFF;
    Prot_CAN2_Send_Frame(0x200, data, 8);
}
```

### 6. 底盘任务 (chassis_task.c)

参考旧代码，实现运动学解算和PID控制。

## 发送流程

```
chassis_task → 赋值 tx_current → chassis_can_send() → Prot_CANx_Send_Frame() → 队列 → Task_CANxTransmit → bsp_can_std_transmit()
```
