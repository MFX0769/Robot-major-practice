## 遇到的问题

### 1. Keil链接错误：未定义符号
**错误**：`Undefined symbol chassis_task`
**原因**：chassis_task.c 没有加入Keil工程的链接树
**解决**：手动编辑 .uvprojx 文件，添加文件到 Application 组

### 2. CAN ID冲突
**错误**：`case label value has already appeared`
**原因**：底盘2006的CAN ID (0x201~0x204) 与旧代码的摩擦轮ID定义冲突
**解决**：删除 can_comm.h 中旧的摩擦轮/trigger ID枚举，改为底盘2006的ID

### 3. OpenOCD中文路径问题
**错误**：`couldn't open F:机器人工程实践小车...axf`
**原因**：OpenOCD在处理中文路径时编码问题
**解决**：将axf文件复制到 `C:\temp\` 无中文路径

### 4. OpenOCD反斜杠转义
**错误**：`couldn't open C:	empm_main.axf`
**原因**：PowerShell中的反斜杠 `\` 被当作转义字符
**解决**：改用正斜杠 `/`

### 5. OpenOCD Verify失败
**错误**：`checksum mismatch - attempting binary compare`
**原因**：STM32H7的flash读回机制导致校验不一致
**解决**：跳过verify，直接 `program xxx.axf; reset; shutdown`

### 修复的问题

#### 1. CAN2过滤器缺失底盘电机ID
**问题**：CAN2过滤器只配了0x017, 0x018, 0x206，没有0x201（底盘电机）
**原因**：旧代码的过滤器配置没有更新
**解决**：
```c
bsp_can2_filt_tbl.count = 3;
bsp_can2_filt_tbl.data[0]=FLT_DUAL;
bsp_can2_filt_tbl.data[1]=0x201&0x7ff;  // 右后底盘电机
bsp_can2_filt_tbl.data[2]=0x203&0x7ff;  // 右前底盘电机
bsp_can2_filt_tbl.data[3]=FLT_DUAL;
bsp_can2_filt_tbl.data[4]=0x206&0x7ff;  // yaw 6020
bsp_can2_filt_tbl.data[5]=0x018&0x7ff;  // 陀螺仪
```

#### 2. 舵机PWM引脚修正
**问题**：代码中配置PB0，但硬件没有PB0
**解决**：
- 肩关节: PA0 (TIM2_CH1)
- 肘关节: PA1 (TIM2_CH2)
- 夹爪: PA6 (TIM3_CH1) ← 独立定时器

#### 3. OpenOCD + VS Code调试环境
- 下载ARM GNU工具链到 `D:\GNUARM\xpack-arm-none-eabi-gcc-13.2.1-1.1\`
- 配置VS Code settings.json: `cortex-debug.gdbPath`
