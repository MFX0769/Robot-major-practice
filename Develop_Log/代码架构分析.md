## 一、你的项目：RoboticMajor_Pratice_code

- **主控**: STM32H7 (H743 系列)
- **时钟**: HSE+PLL, 主频 ~400MHz+
- **FDCAN**: 3 路 (FDCAN1/2/3)
- **USART/UART**: 6 路 (UART9, USART1/2/3/6/10)
- **USB**: 设备模式
- **IWDG**: 独立看门狗已开启

### 操作系统
FreeRTOS (CMSIS-OS v1 封装)

### 模式切换状态机 (mode_switch_task)

```
遥控器 SW1 (3档拨杆)
├── UP   → REMOTER_MODE    (遥控手动控制)
├── MI   → PROTECT_MODE    (保护模式, 所有输出清零)
└── DN   → LINE_TRAKING_MODE (自动巡线)
```

### 底盘 (chassis_task)

```
chassis_task (2ms 周期)
└── 根据 ctrl_mode 决定
    ├── PROTECT_MODE: 所有电机输出 0
    ├── REMOTER_MODE: TODO (遥控控制未实现)
    └── LINE_TRAKING_MODE:
        ├── 前进速度 vx_ref (TODO, 待接入遥控)
        ├── 横移速度 vy_ref = 0.5 (硬编码)
        └── 转向 wz_ref = PID(巡线传感器位置, 0)
            └── 用 line_track_pid 计算
        └── chassis_mecanum_resolve(vx, vy, wz)
            └── FL = vx+vy+Lwz, FR=vx-vy-Lwz, BL=vx-vy+Lwz, BR=vx+vy-Lwz
```

### 通信层

- `usart_comm.c/h`: USART 收发封装, 多路 DMA/中断

  - `prot_lk_motor`: LK 电机

  - `prot_T_imu`: IMU

### BSP 层
- `bsp.c/h`: 板级基础配置
- `bsp_can.c/h`: CAN 硬件初始化
- `bsp_usart.c/h`: USART 硬件初始化

### 数学库 (Math/)
大量文件, 核心用到的:
- `pid.c/h`: PID 控制器 (速度环/位置环通用)
- `math_calcu.c/h`: 基础数学工具
- `filter.c/h`: 滤波器

## 二、队友的机械臂代码 (Manipulator_2025)

### 整体架构

```
User/
├── Kinematic_Models/          ← 运动学模型 (核心)
│   ├── forward_kinematic.c/h  ← 正运动学 + 雅可比 + 重力补偿
│   ├── inverse_kinematic.c/h  ← 逆运动学 + 轨迹规划 + 动作序列
├── User_App/
│   ├── joint_task.c/h         ← 机械臂主任务 (3ms 周期)
│   ├── ... (chassis, debug 等与本项目无关)
├── Math_Lib/                  ← 复用即可: pid, math_calcu, kalman_filter
├── User_Drivers/              ← 电机驱动 (DM, 大疆, HT 等)
├── Comm/                      ← CAN 通信
└── Procotol/                  ← 协议
```

### 机械臂硬件
- **7 个关节**: Joint0~Joint6 (J0 电机为 DM 系列, J1~J2 为 DM 电机 + MIT 协议, J3~J6 为云台电机/舵机)
- **驱动方式**: DM 电机用 MIT 协议 (位置/速度/力矩模式), 部分用 CAN 位置闭环
- **末端**: 气泵吸盘 + 阀门控制

### 控制流程 (joint_task, 3ms)

```
joint_task (3ms)
├── Manipulator_Control()     ← 正运动学 + 雅可比 + 重力补偿计算
├── arm_mode_switch()         ← 模式切换 (遥控/键盘)
├── joint_data_input()        ← 根据模式设置各关节目标位置
├── joint_pid_calcu()         ← 位置环+速度环 PID 计算
└── joint_data_output()       ← DM电机 MIT 协议发送
```

### 模式状态机

```
ARM_STOP → 停保护
ARM_STATIONARY → 静止待命
ARM_USE → 随动操纵 (手柄控制)
ARM_KB_USE → 键盘微调
ARM_AIM → 瞄准位
ARM_SILVER_GET → 取银矿 (状态机 0~5)
ARM_GOLD_GET → 取金矿 (状态机 0~4)
ARM_HORIZONTALLY_SET → 平放矿石 (状态机 0~6)
ARM_STORE_BLOCK_GET → 取回矿石 (状态机 0~6)
```

### 逆运动学 (inverse_kinematic.c)

**核心函数 `Inverse_Kinematic()`:**
```
输入 (x, y, z)
  → J0 = atan2(y, x)                    ← yaw 角
  → 将 (x, y) 投影到臂平面得到 D 点
  → 余弦定理: 在 △BOD 中求 B 点极角
  → 余弦定理: 在 △AOC 中求 A 点极角
  → J1 = PI - B_theta - offset
  → J2 = A_theta - PI - offset
```

**轨迹规划 `Trajectory_Planning()`:**
三次多项式插值: `q(t) = a0 + a1*t + a2*t² + a3*t³`
- 支持多段规划 (plan0/plan1/plan2)
- 起止速度可控, 终点自动停止

**动作序列**: 用状态机 + `is_reachedf()` 实现取放矿的时序控制

### 正运动学 (forward_kinematic.c)

**`Manipulator_Control()`:**
1. `Forward_Kinematic()`: 由 J1, J2 角度 → 计算 C, D 点位置
2. `Get_Jacobian_Matrix()`: 2×2 速度雅可比矩阵
3. `Calcu_Compensation()`: 雅可比转置 → 重力补偿力矩

重力补偿是亮点: 它不是手动公式, 而是通过雅可比矩阵 + 重力向量自动算的。
`τ = Jᵀ · G`

### PID 控制 (joint_task.c)

位置环 + 速度环 **串级 PID**:
```
p_set → [位置PID] → v_set → [速度PID] → t_set → DM电机
```
J1, J2 还加斜坡限幅 (`ramp_calc`) + 卡尔曼滤波

## 四、IK 方法讨论 (2026-06-10)

### 几何法（余弦定理）vs DH 参数法

| 维度 | 几何法 | DH 参数法 |
|------|--------|-----------|
| 原理 | 初中三角函数，直接算角 | 4×4 齐次变换矩阵系统化建模 |
| 推广性 | 每种臂型重推公式 | 一套方法通吃所有串联臂 |
| 嵌入式效率 | 一个 arctan 搞定，最快 | 需矩阵乘法或硬编码展开 |
| AI 可辅助度 | **低**（臂型一变就得人肉重推） | **高**（填参数表即可，MATLAB symbolic 自动生成全部公式） |
| 行业地位 | 干活够用 | **通用语言，面试必考** |
| 重力补偿/雅可比 | 手列公式，容易错 | DH → symbolic diff → 自动推导 |

### 最终路线决策

用户目标：通过课设入门机械臂算法（不只看懂，要能用、能迁移）。

**选择 DH 参数法**，理由：
1. AI 时代，参数化方法比几何推理更适合交给 AI 辅助
2. 换臂型只需改 DH 表，不换算法框架
3. 配合 MATLAB symbolic 可实现：
   ```
   DH 参数表 → 正运动学符号推导 → 雅可比符号推导 → IK 闭式解 → C 代码输出
   ```
4. 用户数学功底不深 + 有时间压力 + 有 AI 工具 → DH 是"有希望的路"

### 执行路线

```
① 根据机械尺寸列 DH 参数表（4 参数/关节，30 分钟）
    ↓ AI (MATLAB symbolic)
② 正运动学矩阵自动生成
③ IK 闭式解公式推导 ← 几何法 C 代码干活
④ 雅可比 + 重力补偿（MATLAB symbolic diff 自动求导）
```

### 队友代码参考价值
- 队友用的是几何法（余弦定理）+ 雅可比转置重力补偿
- 他朋友圈说"又算错雅可比了"——正说明手算雅可比容易错
- 用 MATLAB symbolic 自动求导雅可比可以完全避免这类错误
