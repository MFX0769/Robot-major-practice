# 电源拓扑与舵机供电分析

## 电源拓扑

```
24V电池
  ├── 底盘电机 (24V直接供电)
  │     ├── 4x DJI 2006 (麦轮底盘)
  │     └── 1x DJI 6020 (yaw电机)
  ├── 核心板
  │     └── 24→5/3.3V → STM32H7供电
  └── 外置降压模块 (非隔离Buck, 24→5V)
        └── PD30S舵机供电 (肩/肘/夹爪)
```

## 接线确认

### 舵机接线 (PWM模式)
| 线色 | 功能 | 接到 |
|------|------|------|
| 棕/黑 | GND | 外置降压模块 OUT- |
| 红 | VCC | 外置降压模块 OUT+ (5V) |
| 橙/白 | 信号 | H7 PA0/PA1/PA6 |

### GND链路
```
电池GND ──→ 底盘电机GND
        ──→ 核心板GND ──→ H7 GND
        ──→ 外置降压模块输入GND ──→ 外置降压模块输出GND ──→ 舵机GND
```

**全链路GND共地 ✅ (非隔离模块，输入输出GND内部连通)**

### PWM信号回路
```
H7 PA0/PA1/PA6 ──→ 舵机信号线 ──→ 舵机内部电路 ──→ 舵机GND ──→ H7 GND
```

## PWM引脚分配

| 舵机 | H7引脚 | 定时器 | 通道 |
|------|--------|--------|------|
| 肩关节 | PA0 | TIM2 | CH1 |
| 肘关节 | PA1 | TIM2 | CH2 |
| 夹爪 | PA6 | TIM3 | CH1 |
| (备用) | PA7 | TIM3 | CH2 |

## 舵机供电使能

| 功能 | H7引脚 | 说明 |
|------|--------|------|
| 总电源开关 | PA7 | 通过NMOS控制舵机5V供电 |

**NMOS模块接法：**
- 信号输入端 → H7 PA7
- MOS管D极 → 舵机电源正极
- MOS管S极 → GND
- 高电平使能

| 负载 | 电流 |
