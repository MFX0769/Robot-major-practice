## 3. 硬件连接与烧录命令

公司电脑当前：无线 DAP `FAED:4873`、SN `8E74D081`、调试口 COM141@115200。新电脑插入后必须用 `serial.tools.list_ports` 重查 COM 号，不要写死。

**已知可用的烧录 + SWD 放行序列**（DAP 无 nRESET，`halt` 会卡；不要用 `reset`）：

```bash
openocd -f interface/cmsis-dap.cfg \
  -c 'cmsis_dap_vid_pid 0xfaed 0x4873' \
  -c 'transport select swd' \
  -c 'adapter speed 1000' \
  -c 'reset_config none' \
  -f target/stm32h7x.cfg \
  -c 'init; halt; program <hex> verify; exit'

openocd -f interface/cmsis-dap.cfg \
  -c 'cmsis_dap_vid_pid 0xfaed 0x4873' \
  -c 'transport select swd' \
  -c 'adapter speed 1000' \
  -c 'reset_config none' \
  -f target/stm32h7x.cfg \
  -c 'init; halt; mww 0xE000EDF0 0xA05F0000; mww 0xE000ED0C 0x05FA0004; sleep 500; resume; exit'
```

第二段常报 `not halted / context restore failed`，但板子实际会跑起来；以串口 `[SYS]`/`[CAN2]` 是否继续打印为准。

**关键硬件事实**（接回后确认）：
- CAN2：1Mbps；现场 H/L 与丝印相反，交换后通信正常。
- CAN1：4 个 2006（0x201~0x204），尚未收到过真实反馈。
- 6020：ID4，反馈 0x208，控制 0x1FF（电压帧，不是电流帧）。
- yaw 原始 ECD 限位：1260 / 6478。
- 夹爪：PE13 / TIM1_CH3，50Hz、500~2500us。
- IMU 加热：已永久关（PB1 推挽低、TIM3_CH4 不启动）。
