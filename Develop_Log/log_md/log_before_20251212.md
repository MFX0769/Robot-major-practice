📘 日志条目：DMA 缓冲区内存属性与编译器属性
条目	内容
关键词	volatile、__attribute__((section(...)))、.RAM_D1、Cache、DMA
背景	STM32H7 默认开启 D-Cache；CPU 与 DMA 访问同一物理地址时可能出现“数据看得见/看不见”的假象
核心原则	DMA 写入 → CPU 读取 的缓冲区必须同时满足：
1. volatile：防止编译器把读操作优化掉
2. 放在 无 Cache 域 或 手动维护 Cache
语法模板	volatile uint8_t buf[LEN] __attribute__((section(".RAM_D1")));
常用段	.RAM_D1 (D1-SRAM, 无 Cache, DMA 可访问)
.RAM_D3 (D3-SRAM, 也无 Cache)
.AXI_RAM (需确认 MPU 属性)
不加的后果	-O0/-O1 等任意优化等级下都可能出现“Watch 全 0 但外设回显正常”的诡异现象
官方建议	ARM 应用笔记 3215：任何“异步写”内存都应声明 volatile 并确保一致性域
懒人法则	所有串口/SP/I²C DMA RxBuf 直接复制模板 → 不再手动 SCB_InvalidateDCache_by_Addr()
