# 2026-06-08 课设方案讨论记录

## 项目概况
- **课设内容：** 机器人实践小车 + 机械臂采摘（简单场景）
- **验收目标：** 相机给出目标位置 (x, y, z)，控制机械臂让夹爪到达该位置
- **机械臂构型：** 4轴串联（Yaw + 肩关节 + 肘关节 + 夹爪）

## 机械方案决策

### 关节分配
| 关节 | 方案 | 说明 |
|------|------|------|
| Yaw（底座旋转） | **GM6020** | RM 熟悉的电机，CAN 控制，力矩充沛 |
| 肩关节 | **40kg·cm 舵机** | 经估算力矩需求 ~15 kg·cm，余量 2.7 倍，足够 |
| 肘关节 | **舵机** | 力矩需求 ~5.6 kg·cm，更轻松 |
| 夹爪 | **舵机** | |

### 力矩验算（肩关节，最恶劣工况臂水平伸直）
| 部件 | 估重 | 力臂 | 力矩 |
|------|------|------|------|
| 大臂结构 | 200g | 7.5cm | 1.5 kg·cm |
| 肘舵机 | 60g | 15cm | 0.9 kg·cm |
| 小臂结构 | 150g | 22.5cm | 3.4 kg·cm |
| 末端夹爪 | 300g | 30cm | 9.0 kg·cm |
| **合计** | | | **~14.8 kg·cm** |

### 舵机注意事项
- 当前方案采用 **PWM 舵机**，不引入总线/串口舵机的额外通信协议；舵机位置由开环 PWM 标定和机械限位共同保证
- 40kg·cm 持续工作需打折（约 70% ≈ 28 kg·cm）
- 肩关节如果过热，备选方案：抄去年学长方案 GM6020+4310+4310

### 硬件尺寸
- 大臂：150mm | 小臂：150mm | 末端估重：300g

### 2026-06-08 补充：6020 无法用于肩关节
- 6020 自重 ~500g，挪到肩上会严重超载肘关节和 yaw 舵机
- 放弃 6020 备用方案，肩肘固定用舵机，**不闭环直接跑**
- 热管理参考飞机组云台经验：散热片 + 限速度 + 间歇跑

## 控制方案

### 逆运动学
- 4轴几何闭式解（O(1)），不依赖 ROS/MoveIt
- STM32 上直接实现，一个函数搞定

### 电机控制
- GM6020：CAN + 位置指令（RM 常规操作）
- 舵机：PWM 脉宽控制 + 供电使能/失能
- 舵机内部自带位置保持，外部控制侧只做目标角度生成、关节限位和平滑，不额外叠加复杂位置环

### 重力补偿
- 暂不实现，先看臂有没有明显下垂
- 如果需要，肩关节加一行前馈：`τ = m·g·L·sin(θ)`

## 学习与验证路线

1. ✅ 确认舵机型号（力矩够不够已算清，40kg·cm OK）
2. 量实际臂长，写 Python/MATLAB IK 验证（可选）
3. STM32 实现 IK + CAN/PWM 驱动
4. 空载动起来 → 带负载看发热 → 加视觉联动
5. **不用 ROS，不用 CoppeliaSim**
