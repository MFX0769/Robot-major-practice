# 2026-11-25 需求单：机械臂 yaw 双环回迁 + 拖动示教

> 给「短期调试用代码梳理整合」会话执行。
> 基线：`taurus_h7_all@da71dbc`，板上包 `51393bd4`（当前源码全量包 `117e528e`，仅差 `__TIME__` 4 字节）。
> 本需求只描述“要什么”和“大致步骤”，不规定具体写法。

## 一、总目标

让机械臂具备三项能力：
1. yaw（6020）位置/速度双环可手调；
2. 单按钮拖动示教：能进入释力、记录、保存、回放；
3. 四个关节能单独点动，作为调参和示教的最小入口。

## 二、需求 1：yaw 双环回迁

### 要什么
- 恢复 6 月 25 日 `155ab05` 中的 `arm_yaw_pid_init()` / `arm_yaw_pid_calc()` 双环：
  - 位置环反馈：6020 编码器角度；给定：目标 ECD/角度。
  - 速度环反馈：`arm_yaw_motor.speed_rpm`；给定：位置环输出。
  - 输出：`arm_yaw_motor.tx_current`，仍然走现有 `dji_send_current()` 和 CAN2 队列。
- 限位使用实测原始 ECD **1260（左）/ 6478（右）**，不用旧的 1018/3988。
- 目标先夹到限位区间；到达边界后只允许向区间内输出；反馈离线/超时/保护模式必须归零。
- 输出限幅沿用 6020 电压帧 ±25000（0x1FF 是电压帧，不是电流帧；不要改 0x1FE）。
- 必须能在 Keil 里挂变量手调：至少暴露 `target`、`fdb`、`err`、`spd_ref`、`spd_fdb`、`out`、各环 Kp/Ki/Kd、`out_limit`、`enable`。
- 需要串口命令或等价入口：`yaw enable/disable`、`yaw target <ecd>`、`yaw status`，10~20Hz 打印一行 `[YAW]`。

### 不要什么
- 不做 Z-N / relay 自动整定；本轮只把环搭好，参数由用户手调。
- 不改 CAN 位定时、不改 0x1FF/0x208 协议、不改 1Mbps。
- 不在保护模式/示教模式输出非零。

### 验收
- 编译 0 Error / 0 Warning。
- `yaw enable` 后给一个 ±100 ECD 的小目标，电机有跟随动作、`[YAW]` 有值、无 bus-off。
- 给越界目标时目标被夹到 1260/6478；到边界后外向输出为 0、内向仍可动。
- `yaw disable` 或保护模式立即归零。

### 大致步骤
1. 从 `155ab05:Application/arm_task.c` 取两个函数，补 `arm_ctrl` 定义。
2. 限位改成 1260/6478，输出前加 clamp 和边界方向判断。
3. 在 `arm_task` 主循环调用 `arm_yaw_pid_calc()`；未使能时继续发零电流保活。
4. 加 `yaw enable/disable/target/status` 和 `[YAW]` 打印。
5. 编译、烧录，先静态验限位，再小目标验跟随。

## 三、需求 2：拖动示教

### 要什么
- 用板载 **PA15 单按钮**，不依赖遥控器：
  - 长按 2s：进入/退出示教准备态；
  - 短按：标定原点 / 开始记录 / 记录中插一个关键点；
  - 双击：结束并保存 / 从保存态回放；
  - 长按 5s：删除已保存轨迹（需要二次确认，不能一按就删）。
- 状态机至少覆盖：`IDLE`、`READY`（已标原点）、`RECORD`、`SAVED`、`PLAYBACK`、`ABORT`。
- 记录内容：yaw ECD、肩脉冲、肘脉冲、夹爪脉宽；20Hz 采样 + 位移阈值写入；上限 512 点。
- 示教时 yaw 必须零转矩（可手拖），肩/肘必须释力；回放时按记录点插值输出。
- 第一版允许 RAM 缓冲先跑通；第二版必须做片内 Flash A/B 扇区 + CRC32，断电后能重新加载。
- 状态必须可观测：串口日志必须有；有 LED/WS2812 更好。单按钮无显示时必须至少串口可见。
- 异常退出：限位、反馈超时、舵机离线、记录满、CRC 失败、模式冲突 → 立即停止并回 `ABORT/IDLE`。

### 不要什么
- 不做力矩传感器导纳控制、ROS/MoveIt、轨迹规划器。
- 不做节点删除/编辑、多轨迹库、变速回放、样条插值。
- 不在没有原点、没有 ≥2 点、CRC 不对的情况下回放。

### 验收
- 长按 2s 能进入示教，串口状态变化可见。
- 手拖肩/肘/yaw 后能记录 ≥10 点，短按插点有效。
- 双击保存后能从 RAM 回放，肩/肘回到记录姿态；yaw 跟随误差记录实际值，不强行写“通过”。
- 断电重上电后能加载并回放（第二版 Flash）。
- 任意异常能停，不撞限位、不持续输出。

### 大致步骤
1. 先接 PA15 按键到状态机，串口打印状态迁移；不碰 Flash。
2. 复用/修正现有 `servo_teach_begin/poll/end`，确认肩肘释力；yaw 在示教态强制零电流。
3. 加 20Hz 采样 + 阈值 + 512 点 RAM 缓冲；短按插点、双击结束。
4. 加回放：肩/肘按脉冲插值，yaw 用需求 1 的位置环跟随；短按/长按停止。
5. 跑通后再加 Flash A/B + CRC32 + 上电加载。
6. 编译、烧录、按验收项逐条记录原始输出。

## 四、需求 3：四关节单独点动（调参/示教的最小入口）

### 要什么
- 串口命令至少支持：
  - `joint shoulder <pulse>`、`joint elbow <pulse>`、`joint gripper <pulse>`；
  - `yaw target <ecd>`（与需求 1 共用）；
  - `stop`（全部回安全态）。
- 所有命令必须限幅、超时自动归零；保护/示教记录中拒绝运动命令。
- 夹爪走 PE13/TIM1_CH3，50Hz、500~2500us；肩/肘走现有总线舵机接口。

### 验收
- 四个关节各能小幅度动一次，方向记录清楚。
- 越界命令被拒绝或夹到边界，不撞机械限位。

## 五、需求 4：编码器限位的动态验证

- 静态：`yaw monitor` 手拧到左右硬限位，ECD 应约 1260/6478，`round` 不跳变。
- 动态：给越界目标，目标被夹住；到边界后外向输出为 0、内向可动。
- 记录原始 `[YAW]`/`[YAW_LIMIT]` 行，未实测不写“通过”。
