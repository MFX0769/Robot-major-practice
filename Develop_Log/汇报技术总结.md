# 技术方案与实现总结

## 一、项目概述

**课设内容**：机器人实践小车 + 3轴机械臂采摘

**验收目标**：相机给出目标位置(x, y, z)，控制机械臂让夹爪到达该位置

**技术栈**：STM32H743 + FreeRTOS + C语言

## 三、机械臂方案

### 3.1 机械构型

**4轴串联机械臂**：
| 关节 | 功能 | 驱动方式 |
|------|------|----------|
| Yaw | 底座旋转 | GM6020电机 (CAN) |
| Shoulder | 肩关节俯仰 | 40kg·cm PWM舵机 |
| Elbow | 肘关节弯曲 | PWM舵机 |
| Gripper | 夹爪开合 | PWM舵机 |

**关键参数**：
- 大臂长度：150mm
- 小臂长度：150mm
- 末端负载：300g
- 肩关节力矩需求：~15 kg·cm (40kg·cm舵机，余量2.7倍)

### 3.2 控制方案

**逆运动学 (IK)**：
- 采用**4轴几何闭式解**，O(1)复杂度
- 基于余弦定理，无需ROS/MoveIt
- STM32上直接实现，一个函数搞定

**控制流程**：
```
视觉输入(XYZ) → 逆运动学解算 → 关节限位 → 步进平滑 → PWM输出
```

**舵机控制**：
- PWM脉宽控制 (500us~2500us)
- 开环标定 + 机械限位
- 供电使能/失能保护

### 3.3 代码实现

| 文件 | 功能 |
|------|------|
| `arm_task.c` | 状态机、流程编排、视觉输入 |
| `arm_ik.c` | 逆解、关节限位、轨迹平滑 |
| `prot_servo.c` | 角度→脉宽映射、脉宽限幅 |
| `bsp_pwm.c` | TIM2 PWM输出 (PA0/PA1/PB0) |
| `bsp_gpio.c` | 舵机供电使能 (PB1/PB2/PB3) |

## 四、巡线方案

### 4.1 传感器

- 8路灰度传感器
- 阈值判定 → 加权平均得到位置值 `position`

### 4.2 控制算法

```
巡线传感器 → 阈值判定 → 加权平均(position) → PID → 底盘转向(wz)
```

**底盘运动学**：
- 麦克纳姆轮解算
- `FL = vx+vy+Lwz, FR=vx-vy-Lwz, BL=vx-vy+Lwz, BR=vx+vy+Lwz`

---

## 五、通信方案

### 5.1 CAN总线

- 3路FDCAN (FDCAN1/2/3)
- 用于GM6020电机控制
- 波特率：1Mbps

### 5.2 串口

- 6路USART/UART
- DMA接收，中断处理
- 用于遥控器、视觉、调试

### 5.3 视觉通信

- 帧格式：`[0xAA][x_high][x_low][y_high][y_low][flag][0xBB]`
- 串口中断解析 → 提取XYZ坐标 → 机械臂目标输入

## 六、调试工具

### 6.1 逻辑分析仪 (nanoDLA)

- 开源硬件，最高24MHz采样率
- 8通道，支持113种协议解析
- 用于调试PWM、串口、CAN波形

### 6.2 VOFA+

- 上位机调试工具
- 实时显示波形数据
- 用于PID调参、信号观测

### 6.3 Keil5 + OpenOCD

- 编译：Keil MDK-ARM
- 烧录：OpenOCD + CMSIS-DAP
- 调试：VS Code + Cortex-Debug插件

## 八、技术亮点

1. **轻量化IK**：4轴几何闭式解，无需复杂库
2. **模块化设计**：分层架构，易于维护和扩展
3. **PWM舵机方案**：简单可靠，成本低
4. **FreeRTOS多任务**：实时性好，任务解耦
5. **调试工具链**：逻辑分析仪 + VOFA + 串口监控
