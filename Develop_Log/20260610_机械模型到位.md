## COM 自动化尝试（失败）

### 做了什么
尝试用 Python win32com 自动化 SolidWorks 提取零件位置和导出 URDF。

### 结果
- SolidWorks COM 能连接成功、能打开文件、能枚举组件
- `GetTransform2()` 始终返回空 — 原因可能是 Python COM 接口注册/版本兼容问题
- `GetActiveConfiguration()` / 配合读取 — 方法找不到
- STL 导出也因 `GetModelDoc2()` 返回 None 而失败

### 根因
- SolidWorks COM API 在 Python 下的文档和示例极少
- 接口调用依赖于 SolidWorks 版本（2024）和 win32com 的 dispatch 机制
- 手动 GUI 操作 2 分钟的事，自动化花了远不止这点时间还没有结果

### 结论
**COM 自动化路线搁置。** 以后如果有时间可以继续调，但课设时间线不允许。
